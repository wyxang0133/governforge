# 旧资产审计与清理结果

## 结论

旧项目曾把通用聊天、Ollama、本地模型、通用 RAG、任务队列、自建 Coding Agent 和 PR Review Demo 并列拼接。重构后的产品只保留两个有共同买方和数据闭环的领域：**AI Coding 交付治理**与**企业知识 Agent**。

## 已退出运行主线

- Ollama、本地模型下载与本地推理回退。
- 自建 Coding Agent、旧任务队列、独立 PR Review Demo、旧报告页和无后端路由的前端组件。
- Chroma/Qdrant 通用向量库、重复依赖文件、缓存、SQLite 临时库和构建产物。

## 重新引入但已重构的能力

企业知识库不是恢复旧“通用聊天”。新链路具有明确的 Workspace 隔离、管理角色、文档大小/格式限制、分块索引、基于来源回答、安全拦截、反馈、专家升级、成本与审计。

## 当前资产边界

- 生产源代码：`devpilot/`、`web/`。
- 交付与运行：`.github/`、`deploy/`、Dockerfile、Compose、Caddy。
- 单一事实文档：`README.md` 与 `docs/`。
- `.env`、`*.db`、缓存、日志、构建产物均被忽略，不属于交付物。

当前目录没有 `.git` 元数据，因此不能声称已有 release commit/tag 或远端审查记录。接入真实 Git 仓库后再执行发布工作流。

# 生产差距与发布门禁

## 仓库内已补齐

- 交付治理和知识 Agent 两条可操作业务闭环。
- Workspace 隔离、企业身份、RBAC、审计、成本、Trace 和指标。
- 文档上传限制、类型校验、分块索引、低证据拒答和 Prompt Injection 拦截。
- 可选 OpenAI-compatible 模型与确定性零成本降级，模型失败不会中断核心查询。
- 反馈、人工升级、知识分析指标及其审计链路。
- 迁移、测试、容器、Kubernetes、供应链和运维文档基线。

## 仍需目标环境取得的证据

1. 真实 SCM、IdP、模型 Gateway、工单系统和文档源接入。
2. 文档级 ACL、敏感信息检测、删除/留存、Legal Hold 与数据主体流程。
3. 基于真实问答集的检索 Recall@K、回答正确率、引用支持率、拒答率和人工升级率。
4. 模型 Prompt Injection/数据外泄红队、SAST/DAST、渗透与风险接受。
5. 合同价格和真实账单对账；限流、配额、超时、重试和供应商故障演练。
6. 托管 PostgreSQL PITR、目标 Kubernetes 灰度/回滚、容量和跨区恢复。
7. Git 远端、分支保护、CODEOWNERS、签名 release digest 和审批记录。

## 明确不伪装成“已完成”的能力

- 当前检索适合中小规模演示语料，不宣称已达到百万文档向量检索规模。
- 本地样例不代表企业文档权限、数据质量或业务准确率已验收。
- OpenAI-compatible 配置存在不代表任何特定供应商已获企业采购/合规批准。
- Kubernetes 模板存在不代表目标集群网络、WAF、密钥和灾备已验证。

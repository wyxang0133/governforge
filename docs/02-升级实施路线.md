# 升级实施路线与交付状态

## 已完成：最终候选代码基线

1. **交付治理**：GitHub/CI/Gateway → 证据 → Scorecard → 分级策略 → 审批/阻断 → Check/Audit。
2. **企业知识 Agent**：文档导入、解析分块、检索、分类、安全拦截、生成/降级、引用、反馈、专家升级。
3. **身份授权**：OIDC PKCE/JWKS/JIT、SCIM、会话轮换、Workspace/Team/Repository 隔离。
4. **FinOps**：Gateway 和知识助手统一记录 provider/model/token/cost/trace，支持预算与成本看板。
5. **可靠性**：PostgreSQL/Alembic、事务 Outbox、多 Worker、指数退避、死信重放、不可变审计。
6. **生产工程**：结构化日志、Prometheus/OTLP、Compose、Kubernetes、NetworkPolicy、HPA/PDB、备份、供应链签名。
7. **质量证据**：31 项后端测试、Next 生产构建、Playwright 业务 E2E、PostgreSQL 迁移与容器验证链路。

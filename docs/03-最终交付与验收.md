## 建议 SLO 起始值

| SLI | RC 验收 | 生产目标（需 Owner 批准） |
|---|---:|---:|
| Webhook 成功接收 | 99.9% | 99.95% |
| PR 事件到 Check 更新 p95 | ≤ 120s | ≤ 60s |
| 高风险操作误放行 | 0 | 0 |
| 模型网关可用性 | 99.5% | 99.9% |
| 成本计量与账单误差 | ≤ 5% | ≤ 2% |
| 审计事件丢失 | 0 | 0 |
| P1 审批时间 p90 | ≤ 4h | 业务时段 ≤ 2h |
| RPO / RTO | 本地不声称 | 建议 RPO ≤ 15m / RTO ≤ 60m |

## 必须演练的异常场景

- 违法 schema、重复事件、同 key 不同 payload、旧 SHA 晚到。
- GitHub 401/403/409/422/429/5xx，Webhook 重放，Check 响应丢失。
- Model 429/超时/5xx，主备都失败，流式输出中断，预算在并发请求中耗尽。
- Agent 失联、审批超时、审批人离职、发起人尝试自审批。
- PostgreSQL 短断、Outbox 重试耗尽、Worker 双活、审计写入失败。
- 部署健康检查失败、迁移向后不兼容、回滚镜像无法读新 schema。

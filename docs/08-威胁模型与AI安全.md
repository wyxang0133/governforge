# 威胁模型与 AI 安全基线

## 资产与信任边界

- 资产：身份会话、GitHub App 私钥、企业文档、对话、策略、成本和审计证据。
- 外部边界：浏览器、GitHub/CI/Gateway、IdP/SCIM、模型供应商、工单系统。
- 内部边界：API、Worker、PostgreSQL、知识检索和模型适配器。

## 主要威胁与现有控制

| 威胁 | 当前控制 | 生产补充 |
|---|---|---|
| Webhook 伪造/重放 | HMAC、Delivery 唯一键、可信 Installation 映射 | WAF、时间窗、轮换演练 |
| 跨租户访问 | Workspace 查询过滤、Token/Header 校验、RepositoryGrant | PostgreSQL RLS、租户逃逸测试 |
| 会话窃取/重放 | HttpOnly Cookie、Refresh 轮换、家族吊销 | CSP nonce、设备/风险策略 |
| Prompt Injection | 输入模式拦截、来源只作数据的系统规则、低证据拒答 | 红队语料、输出 DLP、供应商内容策略 |
| 文档投毒 | 仅管理角色写入、格式/大小限制、审计、软归档 | 审批发布、恶意文件扫描、来源签名 |
| 敏感信息外发 | 默认模型关闭、最小上下文、禁止日志记录 Prompt/源码 | 文档 ACL、PII/Secret DLP、区域化 Gateway |
| 幻觉/错误承诺 | 引用、置信度、无证据拒答、反馈和人工升级 | 金标评测集、专家抽检、领域阈值 |
| 成本失控 | UsageEvent、预算与价格配置 | 供应商配额、并发限流、账单对账 |
| 外部副作用丢失 | 事务 Outbox、重试、死信、受控重放 | 下游幂等合同和故障演练 |
| 审计篡改 | 应用与 PostgreSQL 只追加约束 | WORM 归档、Legal Hold、独立审计账号 |

## 上线红队用例

- 文档与问题分别注入“忽略系统规则”“输出其他租户文档”“泄露系统提示”。
- 上传超限、空 PDF、伪造扩展名、恶意压缩对象和包含密钥的文档。
- 低权限用户写入/归档知识、读取他人会话、评价或升级他人消息。
- 模型超时、429、500、畸形 JSON、超长回答和高成本响应。
- Workspace Header、JWT tenant、GitHub installation 三者不一致。

高危项未修复或未获得书面风险接受时，生产结论必须为 NO-GO。
